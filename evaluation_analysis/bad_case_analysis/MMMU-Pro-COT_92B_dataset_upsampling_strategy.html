技术与工程

基础科学

人文与社科

商业与经管
统计检验与案例映射；假设→统计量→结论。
医疗与健康
医学影像病理定位、阴性检查与鉴别诊断；仅补高难。
艺术与设计
视觉细节、图表、AI图像鉴别与艺术史；保持覆盖。

判断口径：不能仅用总 rows 判断“数据够不够”。本次把 MMMU-Pro 领域表现与 175 个已加入数据集的 primary/secondary label、difficulty、visual_dependency、reasoning_depth 汇总对照。结论是：主要问题是领域结构与任务形态不匹配，数量不足只在少数领域成立。

联合两份错误 case 报告后的重新诊断

新增依据：MMMU-Pro 报告指出技术与工程（-2.80pp）、基础科学（-1.27pp）、人文社科（-1.22pp）相对 Qwen 较弱；E2E 报告虽然 Pangu-92B 在主要领域均不低于 Qwen，但其自身错误集中在医学与健康（24/86）、数学（21/86）、植物科学与园艺（20/86）、地球与空间科学（8/86），并指出图像细节提取、知识点定位、答案核对是主要原因。因此，science 不能作为一个整体处理。
