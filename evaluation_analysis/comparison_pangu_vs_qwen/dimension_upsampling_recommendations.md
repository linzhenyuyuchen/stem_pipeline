## 口径

- 弱项范围：Pangu 相对 Qwen 的测评差值 `Δ(pp) < 0`。
- 排序：每个维度内按测评样本数 `n` 从大到小排列。
- 新增有效倍数：该标签在建议上采样后的 occurrence ÷ 原始 occurrence；这是数据集上采样方案映射到标签后的结果，不是独立设置的标签权重。
- occurrence 是标签出现次数，不等同于去重样本数；一条样本可能贡献多个知识点 occurrence。
- 新增数据没有覆盖的标签无法通过本轮上采样补齐，表中标记为“不可上采样”。
- 知识点训练分布受源 HTML Top-200 展示范围影响，存在长尾截断，相关建议应视为保守估计。

- 领域和体裁：新增数据覆盖全部负向弱项，且上采样后合并弱项占比提高，可直接按建议采样量执行。

- 执行数据集级采样时，以对应的逐数据集建议为准；本文档用于检查各维度标签最终得到的实际增益和遗漏。
